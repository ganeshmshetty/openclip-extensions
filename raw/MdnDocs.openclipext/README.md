# MDN Docs

Quickly search Web APIs, JavaScript, CSS, and HTML documentation on MDN Web Docs.

## Features

- **Direct Search**: Opens search results on `developer.mozilla.org` matching your selected query.
- **Fast Lookup**: Ideal for web developers checking syntax, browser compatibility, and standard specifications.

## Usage Examples

- Select `"fetch"` or `"Array.prototype.reduce"` and trigger **MDN Docs** to open the MDN documentation in your default browser.
