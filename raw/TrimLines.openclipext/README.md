# Trim Lines

Strip leading and trailing whitespace from every line of selected text.

Select multi-line text and choose **Trim Lines** in OpenClip to clean up extraneous spaces and tabs from the start and end of every line.

## Features

- **Cleans Whitespace**: Strips unnecessary spaces and tabs while preserving overall line structure.
- **Code & Data Formatting**: Cleans up messy copy-pastes, log outputs, or code blocks.
- **Fast & Offline**: Runs entirely on your Mac.

## Options

- **Trim**: `Both` (default) trims both ends of each line, `Start only` removes just the leading indentation, and `End only` removes just trailing spaces.

## Requirements

- OpenClip 1.0.0 or later.
