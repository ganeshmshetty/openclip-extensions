# QR Code

Generate QR codes instantly from any selected text, link, address, or Wi-Fi configuration string on your screen.

## Features

- **Instant Generation**: Creates a high-resolution QR code directly from your selected text with zero latency.
- **Interactive Result Card**: Live preview right on your screen without opening a browser or third-party app.
- **Save & Copy**: Copy the generated QR code image (⌘C), save it directly to your configured default folder (⏎ / ⌘S), or drag and drop it into other apps.
- **Dual Formats**: Choose between high-resolution PNG or vector SVG in options.
- **Adjustable Error Correction**: Select between L, M, Q, or H error correction levels.

## Options

- **Format**: `png` (default) or `svg`.
- **Error Correction**: `M` (standard default), `L` (low), `Q` (medium-high), or `H` (maximum recovery).

## Usage

1. Select any text, link, or phone number.
2. Click the **QR Code** action in OpenClip.
3. Preview the code, press ⏎ to save, ⌘C to copy the image, or drag it straight into Notes, Slack, Finder, or any messaging app.
