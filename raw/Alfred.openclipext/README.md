# Alfred for OpenClip

Activate [Alfred](https://www.alfredapp.com)'s search field with the selected text — hand any selection straight to Alfred as a query.

## Features

- **Search in Alfred** — opens Alfred's command field with the selected text pre-filled.
- Your Alfred workflows and custom search prefixes work as usual; add a workflow keyword in Alfred afterwards if you like.
- Works with any app on macOS.

## Usage Examples

1. Select a word or phrase.
2. Click **Alfred → Search in Alfred**.
3. Alfred pops up with your text ready — press Return to search, or prepend a workflow keyword before running it.

## Requirements

- [Alfred 4 or 5](https://www.alfredapp.com) installed (Powerpack not required).
- OpenClip's Accessibility permission for text selection.
- On first use, allow OpenClip to control Alfred in the macOS Automation prompt.

## Privacy

The selected text is passed to Alfred through a local Apple Event on your machine. No network requests, analytics, or tracking are involved.
