# Bear Notes

Create a new note in [Bear](https://bear.app) with the selected text.

## Features

- **Direct Bear Integration**: Uses Bear's official `x-callback-url` protocol.
- **Instant Capture**: Send quotes, snippets, or draft ideas directly into Bear as a new note.

## Usage

1. Select text in any application.
2. Invoke OpenClip and choose **Bear Notes**.
3. Bear opens with a new note containing your selected text.
