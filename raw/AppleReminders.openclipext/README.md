# Apple Reminders

Quickly add a new reminder task to Apple Reminders from your current text selection.

## Features

- **One-Click Task Creation**: Adds selected text as a task title directly to your default Reminders list.
- **Non-Intrusive**: Runs via native AppleScript in the background with a confirmation toast.

## Usage

1. Highlight any task item or text.
2. Invoke OpenClip and select **Apple Reminders**.
3. A new reminder is instantly created in your default list.
