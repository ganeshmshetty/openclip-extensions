# Underscore to Space

Replace every underscore (`_`) in the selected text with a space.

Select text anywhere on your Mac and choose **_ → Space** from OpenClip. The action only appears when the selection contains an underscore.

## Features

- **Readable names**: Turns `snake_case` identifiers and file names into plain words.
- **Exact replacement**: Each `_` becomes one space; nothing else in the text changes.
- **Local Transformation**: Processes text instantly on your Mac.

## Usage Examples

- `nome_do_arquivo` → `nome do arquivo`
- `user_profile_card` → `user profile card`
- `Relatorio_Final_2026.pdf` → `Relatorio Final 2026.pdf`

## Requirements

- OpenClip 1.0.0 or later.
