# Sort Numerical

Sort selected lines of text by numerical value.

Select lines containing numbers anywhere on your Mac and trigger **Sort Numerical** from OpenClip to order them in ascending numeric order.

## Features

- **Numeric Value Sorting**: Orders lines based on numeric values rather than raw character sorting.
- **Handles Integers and Decimals**: Parses positive and negative numerical values.
- **Fast Local Execution**: Operates completely offline with zero latency.

## Usage Examples

```text
10
2
100
1
```
becomes:
```text
1
2
10
100
```

## Requirements

- OpenClip 1.0.0 or later.
