# Markdown Strikethrough

Format selected text with Markdown strikethrough syntax.

## Features

- **Markdown Formatting**: Wraps selected text in double tildes (`~~selected text~~`).
- **Whitespace Preserving**: Intelligently keeps surrounding leading and trailing whitespace outside the strikethrough tags.

## Usage Examples

- Select `"deprecated"` → Returns `~~deprecated~~`.
- Select `" old feature "` → Returns ` ~~old feature~~ `.
