# Firecrawl

Select a URL and choose **Scrape to Markdown**. Firecrawl fetches the page and OpenClip shows its main content as Markdown in a result card, ready to copy.

## Configuration

1. Sign in at [firecrawl.dev](https://www.firecrawl.dev) and copy your API key (starts with `fc-`).
2. Paste it into the extension's **API Key** setting. OpenClip stores it as a secret.

## Requirements

- A Firecrawl account. Each scrape uses your Firecrawl credits.
- OpenClip 1.7.0 or later.

The selected URL is sent to Firecrawl.
