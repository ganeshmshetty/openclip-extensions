# Line Count

Count the lines in any selected text instantly inline inside OpenClip.

## Features

- **Live Inline Results**: See the line count directly inside the popup bar button and search palette without needing to click.
- **Newline Aware**: Counts both LF and CRLF line endings across single or multi-line selections.
- **Copy or Paste**: Click to paste the line count into your current app, or right-click to copy it to your clipboard.

## Examples

- Select three lines → Displays **`3 lines`** inline.
- Select a single line → Displays **`1 line`** inline.
