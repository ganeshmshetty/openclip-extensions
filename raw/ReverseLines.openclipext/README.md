# Reverse Lines

Reverse the vertical order of lines in the selected text.

## Features

- **Invert Order**: The last line becomes the first line, and the first becomes the last.
- **Preserves Line Contents**: Each line's internal content remains unchanged.

## Usage Examples

- Given:
  ```text
  Step 1
  Step 2
  Step 3
  ```
  Returns:
  ```text
  Step 3
  Step 2
  Step 1
  ```
