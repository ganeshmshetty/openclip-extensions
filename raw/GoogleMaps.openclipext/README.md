# Google Maps

Look up any selected address, business name, or coordinates on Google Maps.

## Features

- **Fast Location Lookup**: Open directions or places directly from emails, documents, or websites.
- **Coordinates & Places**: Works seamlessly with street addresses, landmarks, and GPS coordinates.

## Usage Examples

- Select `"Eiffel Tower"` → Opens Google Maps with Eiffel Tower pinned.
- Select `"1600 Amphitheatre Pkwy, Mountain View, CA"` → Opens location in Google Maps.
