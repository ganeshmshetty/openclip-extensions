# camelCase

Convert selected text into `camelCase`.

## Features

- **Smart Word Splitting**: Handles space-separated, snake_case, kebab-case, and PascalCase words.
- **Developer Ready**: Perfect for variable names, JSON keys, and coding conventions.

## Usage

1. Select text (e.g. `user first name` or `USER_FIRST_NAME`).
2. Invoke OpenClip and choose **camelCase**.
3. Result: `userFirstName`.
