# Bold

Toggle bold formatting on the selected text using the standard macOS Command+B shortcut.

## Features

- **Universal Formatting**: Simulates `⌘B` in rich text editors, markdown editors, document apps, and browsers.
- **Instant Toggle**: Quickly bold or un-bold highlighted text without lifting your hands from your workflow.

## Usage

1. Select text in a rich text editor (e.g. Pages, Notes, Google Docs, Word).
2. Invoke OpenClip and choose **Bold**.
