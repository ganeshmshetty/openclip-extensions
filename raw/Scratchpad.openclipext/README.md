# Save to Scratchpad

Append selected text to [Scratchpad](https://sindresorhus.com/scratchpad) by Sindre Sorhus, the single always-available note for your menu bar.

## Features

- **One-Click Append**: Adds the selected text to the end of your scratchpad.
- **Stays Out of the Way**: Scratchpad's window stays hidden, so you never leave what you're doing.
- **Syncs Everywhere**: Works with Scratchpad's optional iCloud sync across your devices.

## Requirements

- macOS with [Scratchpad](https://sindresorhus.com/scratchpad) installed.
- OpenClip 1.1.0 or later.

## Usage

1. Select any text.
2. Click **Scratchpad** in the OpenClip action bar.
3. The text is appended to your scratchpad.

Icon from [Material Symbols](https://fonts.google.com/icons) (`add-notes`, Apache License 2.0), the same icon Scratchpad's own PopClip snippet uses.
