# Drafts Note

Create a new note in [Drafts](https://getdrafts.com) from the selected text.

## Features

- **Native Drafts URL Scheme**: Instantly passes the selection into Drafts via `drafts://create?text={text}`.
- **Quick Capture**: Capture notes, tasks, or snippets directly into your Drafts inbox.

## Usage

1. Select text in any application.
2. Invoke OpenClip and select **Drafts Note**.
3. Drafts opens with a new draft containing your selection.
