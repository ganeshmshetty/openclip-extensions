# Underline

Toggle underline formatting in rich text editors.

Select text in any word processor, rich text editor, or email client and trigger **Underline** from OpenClip to toggle underline formatting using `⌘ + U`.

## Features

- **Universal Keypress**: Sends the standard macOS `Command + U` shortcut.
- **Quick Formatting**: Works across Apple Notes, Mail, Pages, Microsoft Word, Google Docs, and more.

## Requirements

- OpenClip 1.0.0 or later.
