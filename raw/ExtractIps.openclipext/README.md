# Extract IPs

Extract all IPv4 addresses from selected text into a clean, newline-separated list.

## Features

- **IPv4 Recognition**: Matches valid IPv4 addresses (`0.0.0.0` - `255.255.255.255`) embedded within server logs, command outputs, or configuration dumps.
- **Deduplication**: Removes duplicates to produce an ordered, distinct list.
- **Fast Troubleshooting**: Speed up network analysis and security incident response.

## Usage Examples

1. Select terminal output, firewall logs, or configuration files containing IP addresses.
2. Open OpenClip and choose **Extract IPs**.
3. Paste or copy the extracted IP addresses.
