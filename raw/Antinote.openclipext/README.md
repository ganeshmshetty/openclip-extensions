# Antinote

Quickly capture selected text to [Antinote](https://antinote.app), the minimalist scratchpad for macOS.

## Features

- **Left-Click (Primary)**: Create a brand new note containing the selected text.
- **Right-Click (Secondary / ⇧-Click)**: Append the selected text directly to your active note.
- **Customizable**: Configure your preferred left-click behavior in extension settings.

## Options

- **Left-Click Action** (`defaultAction`):
  - `create` (Default): Left-click creates a new note; right-click appends to the current note.
  - `append`: Left-click appends to the current note; right-click creates a new note.

## Requirements

- macOS with [Antinote](https://antinote.app) installed.
- OpenClip 1.1.0 or later.
