# Dash Documentation

Search API documentation and offline docsets in [Dash for macOS](https://kapeli.com/dash).

## Features

- **Instant Docset Search**: Highlight any class, function, method, or keyword and jump directly to its Dash documentation page.
- **Docset Keyword Support**: Works with Dash syntax and keyword prefixes (e.g., `python:requests`, `swift:URLSession`, or `mdn:fetch`).
- **Offline Speed**: Queries your locally installed docsets in Dash without requiring an internet connection.

## Requirements

- [Dash for macOS](https://kapeli.com/dash) installed.

## Usage

1. Select a method name, class name, or programming term (e.g., `UIView`, `docker run`, or `sqlite:SELECT`).
2. Click **Dash** in the OpenClip action bar.
3. Dash opens immediately focused on the matching documentation topic.
