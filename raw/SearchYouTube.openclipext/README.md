# Search YouTube

Search YouTube for videos matching the selected text.

## Features

- **Instant Search**: Launches your default browser directly to YouTube video search results (`youtube.com/results?search_query=...`).
- **Quick Lookup**: Find music, tutorials, guides, and reviews in seconds from any text selection.

## Usage Examples

- Select `"macOS window management tips"` and choose **Search YouTube** to view matching videos.
