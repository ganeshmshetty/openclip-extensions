# Join Lines with Commas

Join multiple lines of text into a single comma-separated list.

## Features

- **List Flattening**: Converts newline-delimited lists into a single line joined with `, `.
- **Trims Entries**: Cleans up leading and trailing whitespace on each line.

## Usage Examples

- Input:
  ```text
  Apple
  Banana
  Orange
  ```
- Output: `Apple, Banana, Orange`
