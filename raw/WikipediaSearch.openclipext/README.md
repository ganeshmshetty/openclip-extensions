# Wikipedia Search

Look up selected text or topics directly on Wikipedia.

Select any word, topic, or phrase in any application and choose **Wikipedia** from OpenClip to open Wikipedia search results in your default browser.

## Features

- **Instant Knowledge Lookup**: Quickly search Wikipedia for historical events, definitions, biographies, or scientific terms.
- **Default Browser Integration**: Opens searches directly in your chosen web browser.

## Requirements

- OpenClip 1.0.0 or later.
- Active internet connection.
