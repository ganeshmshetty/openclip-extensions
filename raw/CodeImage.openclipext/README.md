# Code Image

Turn any selected code snippet into a styled PNG or SVG image card, completely offline.

## Features

- **12 built-in themes**: Choose from classic frosted gradients (`Breeze`, `Candy`, `Crimson`, `Midnight`, `Sunset`, `Meadow`), architectural frames (`Blueprint`, `Emerald`, `Glass`, `Bitmap`), and minimal styles (`Noir`, `Sand`).
- **Dark & Light modes**: Every theme adapts its window tint, highlight rim, and syntax palette to Dark or Light mode.
- **Automatic language detection**: Highlights 26 common programming languages offline with `highlight.js` and automatically dedents copied snippets.
- **Native PNG & SVG export**: Renders crisp `1x`, `2x`, or `3x` PNGs and SVGs directly in OpenClip's preview card for one-click Copy, Save, or drag-and-drop.

## Configuration

- **Theme**: Pick from 12 unified backdrop, frame, and syntax themes.
- **Dark mode**: Switch between Dark and Light appearance.
- **Show background**: Toggle the outer backdrop and padding on or off.
- **Show line numbers**: Toggle the line-number gutter.
- **Padding (pixels)**: Choose `16`, `32`, `64`, or `128`.
- **Window title (optional)**: Set a custom centered header title (defaults to the detected language).
- **Format**: Export as `png` (default) or `svg`.
- **PNG scale multiplier**: Choose `1`, `2` (default), or `3`.
