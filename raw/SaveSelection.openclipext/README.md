# Save Selection as File

Turn any selected text into a real file — in one action, from any app.

Select some text, open OpenClip, and choose **Save as File**. A native file card appears,
so you can drag it into Finder or another app, copy the file itself to the clipboard, Quick
Look it, or save it wherever you want.

## Features

- **Five formats**: `.txt`, `.md`, `.csv`, `.json`, and `.html`, chosen from a single setting.
- **Custom file name**: set your own name, or leave it and get `selection.<ext>`.
- **Optional timestamp**: append the date and time (`selection-2026-09-25-144112.txt`) so
  repeated saves never clash.
- **Native file result card**: preview, drag, Copy File, Quick Look, and Save — no intermediate
  copy/paste step.

## Options

| Option | Description |
| :--- | :--- |
| **File format** | `txt` (default), `md`, `csv`, `json`, or `html`. |
| **File name** | Base name for the file, without the extension. Defaults to `selection`. |
| **Append date and time** | Adds a `YYYY-MM-DD-HHMMSS` suffix to the file name. |

## Usage

1. Select the text you want to keep.
2. Open the OpenClip popup and run **Save as File**.
3. Drag the card out, or use its **Save** / **Copy File** buttons.

## Requirements

- OpenClip 1.7.0 or later (native file output).
