# Task Lines

Convert selected lines into Markdown task checkboxes.

Highlight a list of items and choose **Task Lines** in OpenClip to prefix each non-empty line with Markdown task list checkbox syntax (`- [ ] `).

## Features

- **Markdown Checkboxes**: Converts lines into `- [ ] Task item` syntax.
- **Smart Formatting**: Skips empty lines and preserves indentation.
- **Great for Note Taking**: Perfect for Obsidian, GitHub, Bear, Notion, and Markdown documents.

## Usage Examples

```text
Buy milk
Finish report
Call dentist
```
becomes:
```text
- [ ] Buy milk
- [ ] Finish report
- [ ] Call dentist
```

## Requirements

- OpenClip 1.0.0 or later.
