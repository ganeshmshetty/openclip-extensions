# snake_case

Convert selected text into lowercase `snake_case`.

Select text anywhere on your Mac and choose **snake_case** from OpenClip to transform spaces, hyphens, and mixed casing into underscore-separated lowercase words.

## Features

- **Identifier Formatting**: Converts strings into standard Python, Ruby, and SQL identifier format.
- **Intelligent Word Splitting**: Handles camelCase, PascalCase, hyphenated strings, and spaced text.
- **Local Transformation**: Processes text instantly on your Mac.

## Usage Examples

- `HelloWorld` → `hello_world`
- `user-profile-card` → `user_profile_card`
- `Get User Data` → `get_user_data`

## Requirements

- OpenClip 1.0.0 or later.
