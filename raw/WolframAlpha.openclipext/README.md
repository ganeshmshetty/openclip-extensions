# Wolfram Alpha

Query the Wolfram Alpha computational intelligence engine using selected text.

Select a math equation, scientific query, unit conversion, or factual question and choose **Wolfram Alpha** from OpenClip to compute answers in your browser.

## Features

- **Computational Queries**: Compute mathematical equations, chemical formulas, statistics, and conversions.
- **Browser Search**: Opens computation results directly on `wolframalpha.com`.

## Requirements

- OpenClip 1.0.0 or later.
- Active internet connection.
