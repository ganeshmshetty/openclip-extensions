# Speak Selection

Read the selected text aloud using your system text-to-speech voice.

Select any text in any macOS application and choose **Speak Selection** in OpenClip to hear it spoken through your Mac's default voice.

## Features

- **System Voice Integration**: Uses your configured macOS system voice and speech settings.
- **Speech Status Toast**: Shows a clean speaking indicator while reading your text.
- **Completely Offline**: Powered by macOS native speech synthesis without sending audio over the internet.

## Requirements

- OpenClip 1.0.0 or later.
- macOS text-to-speech configured in *System Settings ▸ Accessibility ▸ Spoken Content*.
