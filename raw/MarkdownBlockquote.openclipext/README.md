# Markdown Blockquote

Format selected text as a Markdown blockquote (`> quote`).

## Features

- **Multi-line Support**: Prepends `> ` to each line of the selected text.
- **Markdown Authoring**: Quickly format quoted text for GitHub comments, documentation, and notes.

## Usage Examples

- Input:
  ```text
  Stay hungry.
  Stay foolish.
  ```
- Output:
  ```markdown
  > Stay hungry.
  > Stay foolish.
  ```
