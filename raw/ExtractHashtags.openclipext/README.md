# Extract Hashtags

Extract all social media hashtags (`#tag`) from selected text into a clean list.

## Features

- **Hashtag Detection**: Finds all `#hashtag` occurrences across posts, drafts, and notes.
- **Clean Output**: Returns unique hashtags formatted on separate lines.
- **Quick Workflow**: Perfect for preparing tags for social media posts or reviewing tags used in documents.

## Usage Examples

1. Select social media copy, captions, or markdown notes containing hashtags.
2. Trigger OpenClip and choose **Extract Hashtags**.
3. Paste or copy the consolidated list of hashtags.
