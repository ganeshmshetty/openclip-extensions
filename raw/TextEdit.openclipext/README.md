# New Document in TextEdit

Create and open a new TextEdit document containing the selected text.

## Features

- **Instant Document Creation**: Opens a fresh, unsaved TextEdit window pre-filled with your highlighted text.
- **Zero Disk Clutter**: Uses macOS standard input piping (`open -f -a TextEdit`), leaving no temporary files on your disk.
- **Quick Scratchpad**: Ideal for pulling log lines, emails, terminal outputs, or notes into a separate window for editing.

## Usage

1. Select any text in any app (browser, Terminal, code editor, or email).
2. Click **TextEdit** in OpenClip.
3. A new TextEdit document immediately opens with your text ready to format, review, or save.
