# PascalCase

Convert selected text to PascalCase (UpperCamelCase).

## Features

- **Identifier Formatting**: Converts spaces, dashes, underscores, and mixed-case strings into `PascalCase`.
- **Developer Friendly**: Great for naming classes, types, React components, and constructors.

## Usage Examples

- Select `"user profile view"` → Returns `"UserProfileView"`.
- Select `"get_user_by_id"` → Returns `"GetUserById"`.
