# Wayback Machine

Look up historical snapshots of any selected URL on the Internet Archive's Wayback Machine.

Select a web address anywhere on your Mac and click **Wayback Machine** in OpenClip to view archived versions of that page.

## Features

- **Archive Lookup**: Opens historical snapshots on `web.archive.org`.
- **Smart URL Detection**: Automatically detects URLs beginning with `http://`, `https://`, or `www.`.

## Requirements

- OpenClip 1.0.0 or later.
- Active internet connection.
