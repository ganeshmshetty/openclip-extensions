# UPPERCASE

Convert selected text to UPPERCASE.

Highlight text in any application and choose **UPPERCASE** in OpenClip to capitalize all letters.

## Features

- **All Caps Conversion**: Converts lowercase and mixed-case text to uppercase.
- **Locale-Aware**: Handles characters and accents cleanly across international languages.
- **Fast & Private**: Operates locally using JavaScript.

## Usage Examples

- `hello world` → `HELLO WORLD`
- `OpenClip for macOS` → `OPENCLIP FOR MACOS`

## Requirements

- OpenClip 1.0.0 or later.
