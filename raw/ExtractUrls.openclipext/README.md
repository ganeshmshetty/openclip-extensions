# Extract URLs

Extract all web links (HTTP/HTTPS) from selected text into a clean, line-separated list.

## Features

- **Link Extraction**: Parses raw URLs and links out of markdown documents, chat transcripts, or email digests.
- **Deduplication**: Removes duplicate URLs while maintaining discovery sequence.

## Usage Examples

1. Select text containing mixed links and commentary.
2. Trigger OpenClip and select **Extract URLs**.
3. Paste or copy the extracted links.
