# Douban for OpenClip

Search [Douban](https://www.douban.com) (豆瓣) for books, movies, music, or local events using the text you've selected. Douban is a popular Chinese community for discovering and rating books, films and music.

## Features

- **Search Books** — search `book.douban.com`.
- **Search Movies** — search `movie.douban.com`.
- **Search Music** — search `music.douban.com`.
- **Search Events** — search local events on `douban.com/event`.
- **Search Douban** — general search across everything at once.
- All items are grouped under a single **Douban** submenu.

## Usage Examples

1. Select a book, movie, musician or event name (Chinese or English).
2. Click **Douban → Search Books** (or Movies / Music / Events / general).
3. Your browser opens the Douban search results for that text.

## Requirements

- OpenClip's Accessibility permission for text selection.
- Douban is a web service — the search happens in your default browser; no Douban app is needed.

## Privacy

The selected text is sent to Douban's public search pages via an ordinary web search URL. No analytics or tracking is added by this extension.
