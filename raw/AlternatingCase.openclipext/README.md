# Alternating Case

Convert selected text to aLtErNaTiNg CaSe (also known as SpongeBob case or mocking text).

## Features

- **Alternating Letter Casing**: Alternates between lowercase and uppercase letters while preserving spaces and punctuation.
- **Instant Transformation**: Replaces selected text directly or copies the transformed text based on your OpenClip preferences.

## Usage

1. Select text in any application (e.g. `mocking text`).
2. Invoke OpenClip and choose **Alternating Case**.
3. Result: `mOcKiNg TeXt`.
