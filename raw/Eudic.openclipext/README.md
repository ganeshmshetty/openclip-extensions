# Eudic

Look up the selected word or phrase in Eudic (欧路词典), the Chinese-English dictionary for macOS.

## Features

- **One-click lookup**: Opens Eudic and shows the dictionary entry for your selection.
- **Both editions**: Works with Eudic Lite (欧路词典 Lite) and Eudic Enhanced (欧路词典 增强版).

## Options

| Option | Description |
| :--- | :--- |
| Eudic Edition | Choose **Eudic Lite** (default) or **Eudic Enhanced** in the extension's settings, matching the app you have installed. |

## Requirements

- [Eudic](https://www.eudic.net/) installed on your Mac.

## Usage

1. Select a word or phrase in any app.
2. Invoke OpenClip, choose **Search In Eudic**.
3. Eudic comes to the front with the lookup result.
