# Square Brackets

Wrap selected text in square brackets `[ ... ]`.

Highlight any text or expression and choose **Square Brackets** in OpenClip to instantly enclose it.

## Features

- **One-Click Enclosing**: Wraps text inside square brackets `[text]`.
- **Ideal for Markdown & Code**: Useful for drafting Markdown links, list indices, or array definitions.
- **Fast & Private**: Operates locally on your machine.

## Usage Examples

- `OpenClip` → `[OpenClip]`
- `123` → `[123]`

## Requirements

- OpenClip 1.0.0 or later.
