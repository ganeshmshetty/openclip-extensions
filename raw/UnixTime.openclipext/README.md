# Unix Time Converter

Convert epoch timestamps to a human-readable UTC date instantly inline inside OpenClip.

## Features

- **Live Inline Results**: See the converted date and time directly in the popup bar button and search palette upon selecting a timestamp.
- **Seconds & Milliseconds**: Plain 10-digit second timestamps (through 2106) are read as seconds; larger values (11–13 digits, past the 32-bit seconds ceiling) are read as milliseconds.
- **Copy or Paste**: Click to paste the formatted date into your current app, or right-click to copy it to your clipboard.

## Examples

- Select `"1725960000"` → Displays **`2024-09-10 09:20:00 UTC`** inline (seconds).
- Select `"1700000000000"` → Displays **`2023-11-14 22:13:20 UTC`** inline (milliseconds).
