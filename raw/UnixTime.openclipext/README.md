# Unix Time Converter

Convert epoch timestamps to a human-readable UTC date instantly inline inside OpenClip.

## Features

- **Live Inline Results**: See the converted date and time directly in the popup bar button and search palette upon selecting a timestamp.
- **Seconds & Milliseconds**: Automatically detects 10-digit second timestamps and 13-digit millisecond timestamps.
- **Copy or Paste**: Click to paste the formatted date into your current app, or right-click to copy it to your clipboard.

## Examples

- Select `"1725960000"` → Displays **`2024-09-10 09:20:00 UTC`** inline.
