# Deduplicate Lines

Remove all duplicate lines from the selection while preserving the original line order.

## Features

- **Unique Lines Only**: Eliminates repeating rows from lists, logs, CSVs, or text blocks.
- **Order Preserving**: Retains the first occurrence of each unique line.

## Usage

1. Select multiple lines with repetitions.
2. Invoke OpenClip and choose **Deduplicate Lines**.
3. Only the unique lines remain.
