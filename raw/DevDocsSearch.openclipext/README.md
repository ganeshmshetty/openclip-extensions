# DevDocs Search

Instant unified API documentation search on [DevDocs](https://devdocs.io).

## Features

- **Fast Documentation Lookup**: Directly searches DevDocs for selected programming languages, libraries, methods, or CSS/HTML documentation.
- **Unified Developer Docs**: Access docs for React, Python, Go, Rust, JavaScript, CSS, and hundreds of others in one fast interface.

## Usage

1. Select a function name, CSS rule, or keyword (e.g. `Array.prototype.slice` or `flexbox`).
2. Invoke OpenClip and select **DevDocs Search**.
3. DevDocs opens in your browser with instant search results.
