# Code Block

Format selected text inside a fenced Markdown code block (` ``` `).

## Features

- **Smart Fencing**: Automatically extends backticks if the selected text contains backticks (preventing syntax breakage).
- **Preserves Indentation**: Keeps your code formatting intact.

## Usage

1. Select code lines in any editor or browser.
2. Invoke OpenClip and choose **Code Block**.
3. The selected code is wrapped in triple backticks.
