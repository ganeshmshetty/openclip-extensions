# Markdown Link

Wrap the selected text as a Markdown link template.

## Features

- **Instant Formatting**: Converts selected text into `[selected text]()` with the cursor ready for a URL.
- **URL Aware**: If a valid URL is already in your clipboard, it formats it directly as `[selected text](url)`.

## Usage Examples

- Select `"OpenClip"` → Returns `[OpenClip]()` (or `[OpenClip](https://example.com)` if the URL is copied).
