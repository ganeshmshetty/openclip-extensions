# Sort Alphabetical

Sort selected lines of text alphabetically.

Highlight a list of lines in any app and choose **Sort Alphabetical** in OpenClip to sort them in ascending alphabetical order (A–Z).

## Features

- **Ascending A–Z Sort**: Reorders lines alphabetically using locale-sensitive comparison.
- **Multi-line Support**: Seamlessly reorganizes lists, code imports, or document headings.
- **Local Processing**: Executes instantly on your Mac.

## Usage Examples

```text
Banana
Apple
Orange
```
becomes:
```text
Apple
Banana
Orange
```

## Requirements

- OpenClip 1.0.0 or later.
