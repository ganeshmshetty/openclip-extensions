# Character Count

Count the characters in any selected text instantly inline inside OpenClip.

## Features

- **Live Inline Results**: See the character count directly inside the popup bar button and search palette without needing to click.
- **Accurate Grapheme Support**: Handles emojis, multi-byte characters, and unicode grapheme clusters accurately.
- **Copy or Paste**: Click to paste the character count into your current app, or right-click to copy it to your clipboard.

## Examples

- Select `"OpenClip"` → Displays **`8 chars`** inline.
- Select `"A"` → Displays **`1 char`** inline.
