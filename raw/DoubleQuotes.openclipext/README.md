# Double Quotes

Wrap the selected text in double quotation marks (`"..."`).

## Features

- **Enclose Selection**: Wraps selected text, strings, or phrases in standard double quotes.
- **Code & Writing**: Quick quoting for JSON strings, search query terms, and dialogue text.

## Usage

1. Select text (e.g. `Hello world`).
2. Invoke OpenClip and choose **Double Quotes**.
3. Result: `"Hello world"`.
