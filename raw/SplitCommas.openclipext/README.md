# Split Commas

Split a comma-separated list into separate lines.

Highlight a comma-delimited string anywhere on your Mac and trigger **Split Commas** in OpenClip to format each item onto its own line.

## Features

- **Clean Line Separation**: Breaks comma-separated items into readable vertical lists.
- **Whitespace Trimming**: Automatically strips unwanted whitespace surrounding each item.
- **Local Text Transform**: Runs purely on your device.

## Usage Examples

- `apple, banana, cherry, date` becomes:
  ```text
  apple
  banana
  cherry
  date
  ```

## Requirements

- OpenClip 1.0.0 or later.
