# Copy as Markdown

Convert rich text / HTML selection into clean Markdown and copy it directly to your clipboard.

## Features

- **Rich HTML to Markdown**: Converts headings, lists, links, bold/italic, blockquotes, and tables into standard Markdown.
- **Configurable Options**:
  - **Heading Style**: Choose between `atx` (`# Heading`) and `setext` (`Heading\n===`).
  - **Bullet List Marker**: Choose between `*`, `-`, or `+`.
  - **Emphasis & Strong Delimiters**: Custom delimiters (`*`, `_`, `**`, `__`).
  - **Link Style**: Inline `[text](url)` or reference style `[text][1]`.

## Usage

1. Select formatted rich text in a browser or document.
2. Invoke OpenClip and choose **Copy as Markdown**.
3. Clean Markdown is copied to your clipboard, ready to paste.
