# Logseq Capture

Quickly capture selected text into Logseq.

## Features

- **Direct Capture**: Uses Logseq's `logseq://x-callback-url/quickCapture` protocol to send notes directly to your journal.
- **Zero Friction**: Highlight text in any application and save it directly into Logseq.

## Requirements

- [Logseq](https://logseq.com) installed on your Mac.
