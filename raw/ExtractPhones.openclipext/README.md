# Extract Phone Numbers

Extract phone numbers from selected text into a clean list.

## Features

- **Flexible Matching**: Recognizes multiple common phone formats, including local numbers and international dialing formats.
- **Deduplicated Output**: Pulls numbers from emails, customer chats, or notes and formats them on separate lines.

## Usage Examples

1. Highlight customer feedback, signatures, or contact lists.
2. Select **Extract Phones** in OpenClip.
3. Paste the clean list of numbers.
