# Fantastical Event

Create a new calendar event in Fantastical from the selected text.

## Features

- **Natural Language Parsing**: Hands off selected text directly to Fantastical's natural language engine (e.g. "Lunch tomorrow at 12pm with Alex").
- **Fast Capture**: Schedule events from emails, chat messages, or browser pages with a single click.

## Requirements

- [Fantastical](https://flexibits.com/fantastical) installed on your Mac.
