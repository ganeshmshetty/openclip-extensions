# Single Quotes

Wrap selected text in single quotes.

Highlight text in any document or input field and choose **Single Quotes** in OpenClip to enclose the selection with `'single quotes'`.

## Features

- **Instant Quoting**: Encloses words, phrases, or code snippets in single quotation marks.
- **Clean Replacement**: Replaces selection or copies quoted text per your OpenClip preference.
- **Private & Local**: Runs entirely locally via JavaScript.

## Usage Examples

- `test_variable` → `'test_variable'`
- `Hello world` → `'Hello world'`

## Requirements

- OpenClip 1.0.0 or later.
