# Things 3

Quickly capture tasks into [Things 3](https://culturedcode.com/things/) from any selected text on macOS.

## Features

- **Instant Capture (Left-Click)**: Select text anywhere on your Mac and click **Things 3** to immediately create a to-do in your Inbox (or schedule it for Today, Evening, Tomorrow, or Someday).
- **Quick Entry with Pre-fill (Right-Click / ⇧-Click)**: Opens Things' native Quick Entry dialog pre-populated with your selected text so you can review tags, deadlines, or project assignments before saving.
- **Optional Note Splitting**: Enable "First line as title" to automatically use the first line of multi-line text as the task title and the rest as notes.
- **Project & Area Filing**: Optionally route captured tasks into a specific Project or Area by default.

## Options

Configure under *Preferences → Actions → Things 3*:

| Setting | Type | Description |
| :--- | :--- | :--- |
| **Schedule for** | Picker | Choose where to add tasks: `inbox` (default), `today`, `evening`, `tomorrow`, or `someday`. |
| **First line as title** | Toggle | When enabled, uses the first line of multi-line selections as the to-do title and places the remainder into the notes. Default: off. |
| **Project or Area** | Text | Optional name of a target Project or Area (e.g. `Work`, `Personal`). |
| **Tags** | Text | Optional comma-separated tags to automatically attach (e.g. `Follow-up, OpenClip`). |

## Requirements

- macOS with [Things 3](https://culturedcode.com/things/) installed.
- Enable the Things URL scheme when prompted by Things on first run (*Things → Settings → General → Enable Things URLs*).
