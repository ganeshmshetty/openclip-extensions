# Shuffle Lines

Randomly shuffle lines of selected text.

Select multiple lines of text anywhere on your Mac and trigger **Shuffle Lines** in OpenClip to randomize their order using the Fisher-Yates shuffle algorithm.

## Features

- **Randomized Line Order**: Shuffles multi-line text evenly and unpredictably.
- **Preserves Line Breaks**: Maintains line separation without altering line contents.
- **Fast & Local**: Executes instantly on your Mac with zero network calls.

## Usage Examples

- Randomize a list of names, items, or brainstorming ideas.
- Shuffle test data or prompts before processing.

## Requirements

- OpenClip 1.0.0 or later.
