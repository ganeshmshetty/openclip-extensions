# Render HTML

Render selected HTML source code and paste it as formatted rich text.

## Features

- **Rich Text Pasting**: Converts raw HTML tags (`<b>`, `<a>`, `<p>`, `<table>`, etc.) into macOS rich text and pastes it into the active editor or document.
- **Dual Format Clipboard**: Supplies both `public.html` and plain text fallbacks.

## Usage Examples

- Select `<strong>Important:</strong> Please review the <a href="https://example.com">guidelines</a>.` and trigger **Render HTML** to paste formatted rich text with active links and bolding.
