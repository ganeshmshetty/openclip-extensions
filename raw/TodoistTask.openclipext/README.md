# Todoist Task

Quickly create a new task in Todoist from selected text.

Select any text on your Mac and trigger **Todoist Task** in OpenClip to open Todoist's Quick Add window with the selection pre-filled.

## Features

- **Quick Capture**: Capture action items, links, or reminders directly into Todoist.
- **Native URL Scheme**: Communicates directly with the Todoist app or web service via `todoist://addtask`.

## Requirements

- OpenClip 1.0.0 or later.
- [Todoist](https://todoist.com) installed or registered URL scheme handler on macOS.
