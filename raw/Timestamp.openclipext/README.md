# Insert Timestamp

Paste the current date and time at your cursor in your preferred format.

## Features

- **Cursor-Friendly**: Can be invoked directly at a bare cursor via the OpenClip command palette (`⌥⌘C`) without needing to select text first.
- **Customizable Formats**: Choose between ISO 8601, full date and time, date-only, or time-only.
- **Instant Pasting**: Directly pastes the formatted timestamp into your active document or terminal.

## Options

Customize formatting in *OpenClip Preferences → Actions → Insert Timestamp*:

| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **Format** (`format`) | Picker | `iso` | Choose between `iso` (ISO 8601), `datetime` (`YYYY-MM-DD HH:MM:SS`), `date` (`YYYY-MM-DD`), or `time` (`HH:MM:SS`). |

## Usage

1. Place your text cursor where you want the timestamp inserted.
2. Open OpenClip (via hotkey or palette).
3. Click or select **Insert Timestamp** to paste the formatted timestamp.
