# Word Count

Count the words in any selected text instantly inline inside OpenClip.

## Features

- **Live Inline Results**: See the word count directly inside the popup bar button and search palette without needing to click.
- **Accurate Word Parsing**: Accurately counts whitespace-separated words across single or multi-line selections.
- **Copy or Paste**: Click to paste the word count into your current app, or right-click to copy it to your clipboard.

## Examples

- Select `"The quick brown fox"` → Displays **`4 words`** inline.
- Select `"Hello"` → Displays **`1 word`** inline.
