# ROT13 Cipher

Apply the ROT13 (rotate by 13 places) substitution cipher to the selected text.

## Features

- **Symmetric Cipher**: Encodes or decodes text using the classic Caesar-style ROT13 cipher.
- **Preserves Casing**: Letters `A-Z` and `a-z` are shifted by 13 positions; numbers and symbols remain unchanged.

## Usage Examples

- Select `"Hello World"` → Returns `"Uryyb Jbeyq"`.
- Select `"Uryyb Jbeyq"` → Returns `"Hello World"`.
