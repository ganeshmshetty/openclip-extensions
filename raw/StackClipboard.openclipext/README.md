# Stack Clipboard

Stack selected text onto your clipboard without replacing existing contents.

Select text in any macOS application and click **Stack** in OpenClip to append or prepend it to your active clipboard.

## Actions

| Trigger | Action | Behavior |
| :--- | :--- | :--- |
| **Left-Click** (Primary) | **Append** | Stacks the selected text onto the end of your current clipboard contents. |
| **Right-Click / ⇧-Click** (Secondary) | **Prepend** | Stacks the selected text onto the beginning of your current clipboard contents. |

## Options

Configure options under *Preferences → Actions → Stack*:

| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **Separator** (`separator`) | Picker | `newline` | Separator between stacked items (`newline`, `space`, `comma`, or `none`). |

## Usage Examples

- Collect research quotes, code snippets, or bullet points from different apps into a single consolidated clipboard buffer before pasting.
- Use Right-Click to insert an important headline at the top of an accumulated list.

## Requirements

- OpenClip 1.3.0 or later.
