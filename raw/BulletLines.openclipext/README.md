# Bullet Lines

Convert plain lines of text into a Markdown bullet list.

## Features

- **Markdown Bullet Formatting**: Prepends `- ` to every non-empty line in the selection.
- **Preserves Line Breaks**: Maintains line endings and empty lines.

## Usage

1. Select multiple lines of text:
   ```
   Apples
   Oranges
   Bananas
   ```
2. Invoke OpenClip and choose **Bullet Lines**.
3. Result:
   ```
   - Apples
   - Oranges
   - Bananas
   ```
