# Paragraph Count

Count the paragraphs in any selected text instantly inline inside OpenClip.

## Features

- **Live Inline Results**: See the paragraph count directly inside the popup bar button and search palette without needing to click.
- **Blank-Line Aware**: Paragraphs are separated by blank lines, so wrapped lines within a paragraph are not over-counted. Unicode paragraph separators (e.g. `U+2029`) and mixed line endings are handled too.
- **Copy or Paste**: Click to paste the paragraph count into your current app, or right-click to copy it to your clipboard.

## Examples

- Select two paragraphs separated by a blank line → Displays **`2 paragraphs`** inline.
- Select a single paragraph → Displays **`1 paragraph`** inline.
