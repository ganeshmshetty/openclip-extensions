# Paste as Plain Text

Paste clipboard text with all rich formatting, HTML, and styling stripped away.

## Features

- **Strip Rich Text**: Pastes pure plain text into any text field, document, or code editor without unwanted fonts, colors, or styles.
- **Works Anywhere**: Can be triggered with an active selection or at a bare cursor via the OpenClip popup or Action Search palette.

## Usage

1. Copy formatted text from any web page, document, or application.
2. In your target application, invoke OpenClip (via hotkey or text selection).
3. Click **Paste Plain Text** to insert plain text directly.
