# Obsidian Capture

Capture selected text into a new note inside Obsidian using URI schemes.

## Features

- **Obsidian URI Integration**: Uses `obsidian://new?content=...` to instantly capture notes.
- **Seamless Note Creation**: Quickly log snippets, thoughts, or web quotes directly into your active Obsidian vault.

## Requirements

- [Obsidian](https://obsidian.md) installed on macOS.
