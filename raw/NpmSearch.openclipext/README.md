# npm Search

Search packages and libraries on the npm registry.

## Features

- **Direct Web Search**: Launches your default browser directly to npm search results (`npmjs.com/search?q=...`).
- **Quick Package Lookup**: Instantly look up JavaScript/TypeScript package details, versions, and documentation.

## Usage Examples

- Select `"zod"` or `"react"` and trigger **npm Search** to view matching npm packages.
