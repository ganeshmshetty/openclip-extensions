# Append to Tot

Append selected text to a chosen dot in [Tot](https://tot.app), the minimalist scratchpad for macOS and iOS.

## Features

- **Direct Append**: Seamlessly appends highlighted text to your designated Tot dot without interrupting your focus.
- **Configurable Dot**: Choose which of Tot's 7 color-coded scratchpad dots receives the text.
- **Native URL Scheme**: Uses the official `tot://` URL scheme on macOS.

## Requirements

- [Tot for macOS](https://tot.app) installed.

## Options

Configure options under *OpenClip Preferences → Actions → Append to Tot*:

| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **Tot Dot** (`page`) | Picker | `1` | Choose which Tot dot (1 through 7) receives appended text. |

## Usage

1. Highlight text in any application.
2. Click **Tot** in OpenClip.
3. The snippet is immediately added to your chosen Tot dot.
