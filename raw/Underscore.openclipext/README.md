# Underscore

Replace all spaces in the selected text with underscores.

Select text anywhere on your Mac and choose **Underscore** in OpenClip to convert spaces to underscores.

## Features

- **Space Replacement**: Transforms whitespace runs into underscore `_` characters.
- **Useful for Filenames & Keys**: Quickly prepare text for filenames, identifiers, or slugs.
- **Local Processing**: Transforms text instantly on your Mac.

## Usage Examples

- `annual report 2026` → `annual_report_2026`
- `OpenClip extensions` → `OpenClip_extensions`

## Requirements

- OpenClip 1.0.0 or later.
