# Apple Notes

Quickly send selected text into a new note using Apple Notes' native sharing service.

## Features

- **Native Sheet**: Uses macOS's native `com.apple.Notes.SharingExtension` to show an inline Notes creation popup.
- **Zero Configuration**: Works immediately without requiring setup or API keys.

## Usage Examples

- Select any paragraph or snippet and click **New Note** to bring up the Apple Notes compose sheet pre-filled with the text.
