# Normalize Spaces

Clean up text by collapsing multiple consecutive whitespace characters into a single space.

## Features

- **Whitespace Cleanup**: Collapses runs of spaces, tabs, and non-breaking spaces into single spaces.
- **Trims Edges**: Removes leading and trailing whitespace from the selection.

## Usage Examples

- Select `"Hello     world,    welcome!"` → Returns `"Hello world, welcome!"`.
