# Craft Docs

Add the selected text to [Craft](https://www.craft.do) documents.

## Features

- **Deep Link Integration**: Uses Craft's native URL scheme to create a new document with your text.
- **Fast Note Capture**: Collect thoughts, clippings, and research straight into Craft.

## Usage

1. Select text in any app.
2. Invoke OpenClip and select **Craft Docs**.
3. Craft opens and creates a new document containing your selection.
