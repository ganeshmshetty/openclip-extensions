# Capitalize Words

Capitalize the first letter of every word in the selected text.

## Features

- **Unicode Aware**: Supports accented characters, international letters, and contractions.
- **Title Formatting**: Fast cleanup for headings, titles, and proper names.

## Usage

1. Select text (e.g. `the quick brown fox`).
2. Invoke OpenClip and choose **Capitalize Words**.
3. Result: `The Quick Brown Fox`.
