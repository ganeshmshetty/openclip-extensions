# Dot Case

Convert selected text to `dot.case`.

## Features

- **Word Joining**: Converts spaces, underscores, and camelCase into lowercase words separated by dots (`.`).
- **Configuration & Namespace Friendly**: Useful for property keys, configuration names, and package naming conventions.

## Usage

1. Select text (e.g. `server max memory` or `user_profile_picture`).
2. Invoke OpenClip and choose **Dot Case**.
3. Result: `server.max.memory` or `user.profile.picture`.
