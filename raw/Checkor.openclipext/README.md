# Checkor

한국어 맞춤법/문법 검사 OpenClip 확장 기능.
Korean spelling/grammar checker OpenClip extension.

## Features

- **[우리말 맞춤법 검사기 Checkor Desktop](https://apps.apple.com/kr/app/%EC%9A%B0%EB%A6%AC%EB%A7%90-%EB%A7%9E%EC%B6%A4%EB%B2%95-%EA%B2%80%EC%82%AC%EA%B8%B0-checkor-desktop/id1238750814?mt=12)** App과 연동하여 한국어 맞춤법/문법 검사 결과를 바로 확인할 수 있습니다.
- By integrating with the **Korean Spell Checker Checkor Desktop** app, you can immediately view Korean spelling/grammar check results.

## Usage

원하는 앱에서 텍스트를 선택한 뒤 OpenClip을 실행하고 **Checkor**를 선택하세요.
Select text in any application, invoke OpenClip, and choose **Checkor**.
