# Save to GoodLinks

Save highlighted links straight to [GoodLinks](https://goodlinks.app), the read-later app for Mac, iPhone and iPad.

## Features

- **One-Click Save**: Quick-saves the link to GoodLinks in the background, without opening the link editor.
- **Smart URL Detection**: Only shows up when the selected text is a full web address (`http://` or `https://`).
- **Syncs Everywhere**: Saved links sync to your other devices through GoodLinks' iCloud sync.

## Requirements

- macOS with [GoodLinks](https://goodlinks.app) installed.
- OpenClip 1.1.0 or later.

## Usage

1. Select any full URL (e.g., `https://example.com/article`).
2. Click **GoodLinks** in the OpenClip action bar.
3. The link is saved to your GoodLinks unread list.
