# Render Markdown

Interpret selected Markdown text and paste it as styled rich text.

## Features

- **Full Markdown Parsing**: Renders headers, lists, bold, italics, blockquotes, code blocks, and links into rich formatted text.
- **Direct Paste**: Replaces selected markdown syntax with rendered rich text in apps supporting rich text (Mail, Pages, Notes, Google Docs, etc.).

## Usage Examples

- Select:
  ```markdown
  # Meeting Notes
  - Action item 1
  - Action item 2
  ```
  and trigger **Render Markdown** to paste formatted rich text directly.
