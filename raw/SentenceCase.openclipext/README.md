# Sentence Case

Convert selected text to sentence case formatting.

Select text in any application and choose **Sentence Case** from OpenClip to capitalize the first letter of each sentence while lowercasing the rest.

## Features

- **Sentence-Aware Capitalization**: Capitalizes the beginning of each sentence based on common punctuation (`.`, `!`, `?`).
- **Clean Formatting**: Keeps proper spacing and sentence structure intact.
- **Local Processing**: Transforms text entirely on your Mac using JavaScript.

## Usage Examples

- `hello world. this is openclip.` → `Hello world. This is openclip.`
- `ALL CAPS SENTENCE. ANOTHER ONE!` → `All caps sentence. Another one!`

## Requirements

- OpenClip 1.0.0 or later.
