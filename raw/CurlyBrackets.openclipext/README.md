# Curly Brackets

Wrap the selected text in curly brackets (`{...}`).

## Features

- **Enclose Selection**: Wraps selected text, variables, or expressions inside `{` and `}`.
- **Code & Template Friendly**: Great for code interpolation syntax, JSON objects, template placeholders, and mathematical sets.

## Usage

1. Select any text (e.g. `userId` or `foo: bar`).
2. Invoke OpenClip and choose **Curly Brackets**.
3. Result: `{userId}` or `{foo: bar}`.
