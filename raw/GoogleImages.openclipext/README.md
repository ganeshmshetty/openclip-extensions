# Google Images

Search Google Images for the selected text without leaving your browser.

## Features

- **Image search for any selection**: highlight a word, a name, a place, or a product and open Google Images results for it.
- **One click, no setup**: uses Google's image search directly; no account or API key required.

## Usage Examples

- Select a product name and choose **Google Images** to see what it looks like.
- Highlight a place name to browse photos of it.
- Select a plant or animal name to find reference images.
