# Can I Use

Quickly look up web browser compatibility tables on [Can I Use](https://caniuse.com) for modern CSS, HTML, and JavaScript APIs.

## Features

- **Direct Search**: Opens Can I Use search results for the selected feature or technology name.
- **Web Developer Essential**: Check browser support without switching windows to open a new tab manually.

## Usage

1. Select any web feature or CSS property (e.g. `grid`, `:has()`, `subgrid`).
2. Invoke OpenClip and choose **Can I Use**.
3. Your default browser opens with compatibility tables for that feature.
