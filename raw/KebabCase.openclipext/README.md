# Kebab Case

Convert selected text to `kebab-case`.

## Features

- **Identifier Formatting**: Splits words by case boundaries and whitespace, joining with hyphens in lowercase.
- **Developer Friendly**: Great for CSS classes, HTML attributes, URLs, and git branch names.

## Usage Examples

- Select `UserProfileCard` → `user-profile-card`
- Select `User profile card` → `user-profile-card`
