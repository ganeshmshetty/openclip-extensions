# Open Links

Open every web link in selected text with one click. Links can appear anywhere in a paragraph or list.

- Appears as a contextual action when the selection contains a web link.
- Opens each distinct URL once, in its first occurrence order.
- Uses the source browser when selecting text in a recognized browser; otherwise uses your default browser.
- Recognizes web links, bare domains, localhost endpoints, and IP endpoints supported by OpenClip.

Requires OpenClip 1.9.0 or later. This package accompanies the native content detection feature and should be published with that release.
