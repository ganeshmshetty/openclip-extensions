# PyPI Search

Search Python libraries and packages on the Python Package Index (PyPI).

## Features

- **Fast Package Lookup**: Launches your default browser directly to `pypi.org/search/?q=...`.
- **Python Developer Tool**: Quickly inspect package descriptions, installation commands, and documentation.

## Usage Examples

- Select `"pydantic"` or `"requests"` and choose **PyPI Search** to view package details on PyPI.
