# UpNote

Create a new note in [UpNote](https://getupnote.com) with the selected text.

## Features

- **Direct UpNote Integration**: Uses UpNote's official [`x-callback-url`](https://help.getupnote.com/resources/x-callback-url-endpoints) endpoint.
- **Instant Capture**: Send quotes, snippets, or ideas straight into UpNote as a new note.
- **Choose a Notebook**: Optionally file every new note into the same notebook.

## Usage

1. Select text in any application.
2. Invoke OpenClip and choose **UpNote**.
3. UpNote opens with a new note containing your selected text.

## Options

- **Notebook (optional)**: The notebook new notes go into, e.g. `Inbox`. Leave it empty to use UpNote's default.

## Requirements

- [UpNote](https://getupnote.com) installed on your Mac.
