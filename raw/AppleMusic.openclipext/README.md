# Apple Music

Search Apple Music for the selected song title, artist, or album name.

## Features

- **Deep Link to Music**: Opens the native macOS Music app or web player directly to the search results.
- **Instant Search**: Quickly look up tracks and artists mentioned in articles, chats, or notes.

## Usage

1. Select a song title, artist name, or album title.
2. Invoke OpenClip and select **Apple Music**.
3. The Apple Music app opens immediately with search results for your selection.
