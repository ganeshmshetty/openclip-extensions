# CONSTANT_CASE

Convert selected text to `CONSTANT_CASE` (also known as screaming snake case or uppercase snake case).

## Features

- **Format Conversion**: Converts spaces, hyphens, and camelCase into uppercase words joined by underscores.
- **Coding Standards**: Ideal for defining constants, environment variables, and enum values.

## Usage

1. Select text (e.g. `api baseUrl` or `max retry count`).
2. Invoke OpenClip and choose **CONSTANT_CASE**.
3. Result: `API_BASE_URL` or `MAX_RETRY_COUNT`.
