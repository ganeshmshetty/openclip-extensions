# OmniFocus for OpenClip

Send selected text to [OmniFocus 4](https://www.omnigroup.com/omnifocus/) as a new Inbox task, or open it in the Quick Entry panel. The first line of the selection becomes the task name; the full text is saved into the task note together with a timestamp.

## Features

- **Add to Inbox** — creates a task directly in the OmniFocus 4 inbox.
- **Quick Entry** — opens OmniFocus' Quick Entry panel and pre-fills a task, so you can adjust the project, tags, or dates before saving.
- Works with any app on macOS.

## Usage Examples

1. Select some text (for example a meeting agenda item or an article snippet).
2. Click **OmniFocus → Add to Inbox** — the task appears in your inbox immediately.
3. Or pick **Quick Entry** if you want to review the task before filing it.

## Requirements

- [OmniFocus 4](https://www.omnigroup.com/omnifocus/) installed (tested with OmniFocus 4 Pro).
- OpenClip's Accessibility permission for text selection.
- On first use, allow OpenClip to control OmniFocus in the macOS Automation prompt.

## Privacy

The selected text is sent to OmniFocus through local Apple Events only. Nothing is transmitted over the network, and no analytics or tracking is involved.
