# Select All

Select all content in the frontmost application using standard keyboard shortcuts.

Trigger **Select All** from OpenClip to instantly send the `⌘ + A` shortcut to the active app.

## Features

- **Quick Action**: Quickly select all text or items in text editors, browsers, and documents.
- **Native Shortcut**: Sends the standard macOS `Command + A` keystroke.

## Requirements

- OpenClip 1.0.0 or later.
