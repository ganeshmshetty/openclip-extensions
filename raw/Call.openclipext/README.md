# Call Phone Number

Dial selected phone numbers directly using macOS FaceTime or your default telephony app.

## Features

- **Smart Phone Number Detection**: Automatically activates when highlighting phone numbers, including international prefixes (`+`), hyphens, parentheses, and spaces.
- **Native macOS Dialing**: Uses the system `tel:` protocol to trigger FaceTime or your connected iPhone for cellular calling.

## Requirements

- macOS FaceTime configured with iPhone Cellular Calls or a compatible telephony application.

## Usage

1. Highlight any phone number (e.g., `+1 (555) 234-5678` or `1-800-555-0199`).
2. Click **Call** in the OpenClip action bar.
3. Confirm the prompt to initiate the call via FaceTime or your default calling app.
