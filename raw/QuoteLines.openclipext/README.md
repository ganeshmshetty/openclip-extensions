# Quote Lines

Enclose each line in the selected text within double quotes.

## Features

- **Line-by-Line Quoting**: Surrounds every line with double quotes (`"line"`).
- **Code & Query Prep**: Handy for constructing array literals, SQL `IN (...)` clauses, or CSV fields.

## Usage Examples

- Given:
  ```text
  apple
  banana
  ```
  Returns:
  ```text
  "apple"
  "banana"
  ```
