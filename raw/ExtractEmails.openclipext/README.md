# Extract Emails

Extract all email addresses from any selected text into a clean, newline-separated list.

## Features

- **Regex Extraction**: Automatically detects and extracts valid email addresses from messy text, logs, or documents.
- **Deduplication**: Removes duplicate email addresses while preserving order of discovery.
- **Copy or Paste**: Output can be pasted directly into your active app or copied to your clipboard based on your OpenClip preferences.

## Usage Examples

1. Select text containing email addresses (e.g. contact lists, email threads, raw logs).
2. Trigger OpenClip and select **Extract Emails**.
3. Receive a clean list containing one email address per line.
