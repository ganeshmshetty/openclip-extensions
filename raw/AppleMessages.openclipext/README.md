# Apple Messages

Share selected text directly via Apple Messages using the native macOS Messages sharing service.

## Features

- **Native macOS Integration**: Invokes the official Apple Messages share sheet with your selected text prefilled.
- **Fast Sharing**: Send links, quotes, or notes to your contacts without manually opening Messages.

## Usage

1. Select text in any application.
2. Invoke OpenClip and select **Apple Messages**.
3. Pick a recipient or conversation in the Messages share popup and press Send.
