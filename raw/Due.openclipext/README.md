# Due for OpenClip

Send selected text to [Due](https://www.dueapp.com/) as a brand-new reminder. Due handles the scheduling — add a time inside the app right after it opens.

## Features

- **Add Reminder** — opens Due with the selected text pre-filled as a new reminder.
- Instant URL-scheme action: no scripts, no permissions, no waiting.
- Works with any app on macOS.

## Usage Examples

1. Select a phrase like *call the dentist tomorrow*.
2. Click **Due → Add Reminder**.
3. Due opens with the reminder pre-filled — set the time and confirm.

## Requirements

- [Due for Mac](https://www.dueapp.com/mac.html) installed.
- OpenClip's Accessibility permission for text selection.

## Privacy

The selected text is passed to Due via its `due://` URL scheme on your machine. No network requests, analytics, or tracking are involved.
