# Open in Browser

Open the selected link in a specific browser. Select any text that contains one or more `http://` or `https://` links, open the **Open in Browser** group, and pick a browser. Every link in the selection opens in that browser.

## Browsers

Safari, Chrome, Chromium, Firefox, Brave, Comet, Dia, DEVONagent Pro, DuckDuckGo, Ecosia, Edge, Helium, iCab, Mullvad Browser, Opera, Orion, Quark, Tor Browser, Vivaldi, Waterfox and Zen.

- The button for the browser you selected the link in is hidden, so you only see the other browsers.
- To hide browsers you don't use, turn their actions off in OpenClip's Actions settings.
- If a browser isn't installed, you get a short message saying so.
- Beta, Dev and Nightly builds of Safari, Chrome, Firefox, Brave and Edge are used when the main build isn't installed.
