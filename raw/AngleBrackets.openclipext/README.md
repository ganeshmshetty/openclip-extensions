# Angle Brackets

Wrap the selected text in angle brackets (`<...>`).

## Features

- **Surround Selection**: Encloses selected words, URLs, placeholders, or identifiers inside `<` and `>`.
- **Markdown & Code Friendly**: Perfect for typing generic types, HTML/XML tags, or email-style links.

## Usage

1. Select any text (e.g. `https://example.com` or `T`).
2. Invoke OpenClip and choose **Angle Brackets**.
3. Result: `<https://example.com>` or `<T>`.
