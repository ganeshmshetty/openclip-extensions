# Number Lines

Prefix each line in the selected text with sequential line numbers.

## Features

- **Sequential Numbering**: Numbers each line starting from 1 (e.g. `1. `, `2. `).
- **Multi-line Formatting**: Perfect for preparing code snippets, lists, instructions, or meeting agendas.

## Usage Examples

- Given:
  ```text
  First item
  Second item
  ```
  Returns:
  ```text
  1. First item
  2. Second item
  ```
