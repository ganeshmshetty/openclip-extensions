# Czech Months

See the English name of a Czech month the moment you select it, right inside the OpenClip popup.

## Features

- **Live Inline Results**: Select a Czech month name and the popup bar button shows its English name (for example `ledna` → **`January`**) without a click.
- **Every Word Form**: Recognises all singular case forms used in Czech dates and prose, such as `leden`, `ledna`, `lednu` and `lednem`, or `červenec`, `července` and `červencem`.
- **Abbreviations**: The standard three-letter abbreviations are recognised when written with their trailing period: `led.`, `úno.`, `bře.`, `dub.`, `kvě.`, `čvn.`, `čvc.`, `srp.`, `zář.`, `říj.`, `lis.`, `pro.` (the period avoids clashes with everyday words such as `pro` or `led`).
- **Forgiving Matching**: Casing, missing diacritics and surrounding quotes or punctuation are ignored, so `Unora`, `ZÁŘÍ` and `„březen“` all work.
- **Only When Relevant**: The button appears only while the selection is a single Czech month name, so it stays out of the way otherwise.
- **Copy or Paste**: Click to paste the English name into your current app, or right-click to copy it to your clipboard.

## Examples

- Select `ledna` → Displays **`January`** inline.
- Select `Unor` → Displays **`February`** inline.
- Select `září` → Displays **`September`** inline.
- Select `pro.` → Displays **`December`** inline.
